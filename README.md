# ЕГЭ-8. Сложное предложение

Интерактивный учебный тренажёр: 99 карточек (55 неверных, 44 верные) и восемь наглядных правил.

Ответы «Верно / Неверно», разбор, журнал ошибок, поиск по ID, перемешивание, сохранение прогресса и личные примеры. Данные ученика сохраняются в его браузере.

Автономный index.html не требует сервера приложений или внешних библиотек.
